# Decodelabs-Data-Analytics-Project2
Exploratory Data Analysis (EDA) using Microsoft Excel

--Project Overview

This project was completed as part of the DecodeLabs Data Analytics Internship. The objective was to analyze e-commerce sales data using Microsoft Excel and identify patterns, trends, and potential outliers.

--Objectives

- Analyze sales performance across products.
- Examine monthly sales trends.
- Analyze order status, payment methods, coupon usage, and referral sources.
- Calculate descriptive statistics.
- Identify potential outliers using the IQR method.
- Analyze the correlation between Quantity and UnitPrice.
- Summarize findings and provide business recommendations.

--Tools Used

- Microsoft Excel
- Pivot Tables
- Excel formulas
- Charts and data visualization
- Descriptive statistics
- IQR-based outlier detection
- Correlation analysis

--Key Findings

- The dataset contains 1,200 orders.
- Total revenue is approximately 1.26 million.
- Chair and Printer generated the highest product-wise revenue, while Phone generated the lowest.
- Nine potential outliers were identified using the IQR method.
- The correlation between Quantity and UnitPrice is approximately 0.015, indicating a very weak linear relationship.

--Project Outputs

- Product-wise revenue analysis
- Product-wise quantity analysis
- Monthly sales trend
- Order status analysis
- Payment method and coupon-wise analysis
- EDA statistics and key findings
- Business recommendations

--Business Recommendations

- Investigate cancelled and returned orders.
- Review lower-performing products to identify sales improvement opportunities.
- Verify potential outliers before correcting records.
- Use monthly sales trends for inventory and sales planning.
